# شتاب‌نگر | داشبورد تحلیل تراکنش‌های بانکی

داشبورد وب فارسی و واکنش‌گرا برای بررسی گزارش‌های ماهانه، مقایسه بانک‌ها و پایش اختصاصی بانک مسکن.

## امکانات
- بارگذاری فایل Excel (`.xlsx` / `.xls`) و CSV از مرورگر
- شاخص‌های کل تراکنش، موفق، ناموفق، نرخ موفقیت و هزینه
- نمودارهای مقایسه بانک‌ها، روند ماهانه، سهم موفق/ناموفق، هزینه و نرخ موفقیت
- فیلتر ماه و بانک، جدول گزارش و خروجی CSV
- رابط راست‌چین فارسی و واکنش‌گرا
- پردازش فایل در مرورگر؛ داده ورودی به سرور ارسال نمی‌شود

## راه‌اندازی
این پروژه استاتیک است. فایل `index.html` را در مرورگر باز کنید یا آن را روی سرویس میزبانی استاتیک قرار دهید. برای کتابخانه نمودار، خواندن Excel و فونت فارسی اتصال اینترنت لازم است.

## انتشار با GitHub Pages
در مخزن به **Settings → Pages** بروید. در بخش Build and deployment گزینه **Deploy from a branch**، شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید. پس از انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.

## قالب پیشنهادی فایل ورودی
یک ردیف برای هر بانک و ماه. سرستون‌ها می‌توانند فارسی یا انگلیسی باشند؛ نمونه: `ماه`، `بانک`، `کل تراکنش`، `موفق`، `ناموفق`، `ناموفق هزینه‌دار`، `هزینه کل`. داده‌های نمایشی فقط برای مشاهده ظاهر داشبورد هستند و آمار واقعی نیستند.
